# License scope

The private Windows project had no explicit top-level open-source license at
the time of the preparation audit. The owner approved GPL-3.0-or-later for the
R PROJECT-owned client source, build scripts and custom artwork and authorized
public publication on 2026-11-07. Third-party licenses remain separate.

Third-party source, fonts, brand geometry, data and upstream binaries retain
their own license terms and copyright notices. The project license
does not relabel Wintun's signed prebuilt DLL as GPL. No proprietary binary is
silently made open source by copying a GPL license beside it.

Publishing this client would allow others to use, modify and redistribute its
GPL-covered code under the license, including commercial use. It would not
publish the backend, admin panel, subscription database or private signing key,
and would not grant access to the R VPN service. Separate service subscriptions
can remain paid. The application draft explicitly discloses the private service
dependency so SignPath can assess its program's scope.

The GPL text does not grant third-party trademark endorsement. R VPN / R PROJECT
names identify this project. No claim of registered trademark status is made.
